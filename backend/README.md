历史记录中的后台采用 Python 服务、SQLite 和静态 HTML/JavaScript/CSS，提供项目台账、参与决策、领件状态、截止日历、CA 管理、附件、在线发现、操作记录与导出，并支持置顶、弃标和恢复。默认台账隐藏过期及已弃标项目。
