# 招标项目管理与跟进流程

面向纯软件开发、音视频、RTC、直播、语音及智能客服项目，整理项目发现、公告核验、采购文件分析和台账统计的方法。

## 当前内容

本仓库目前提供执行流程、查询配置和原后台源码接入说明。原后台使用 Python HTTP 服务、SQLite 和静态前端；其完整源码尚未导入，`backend/` 当前不能启动应用。

| 目录 | 用途 |
| --- | --- |
| [`backend/`](backend/README.md) | 后台源码预留目录、导入清单和验收要求 |
| [`docs/workflows.md`](docs/workflows.md) | 从查找新项目到核验、去重、统计和日常更新的执行流程 |
| [`docs/backend-recovery.md`](docs/backend-recovery.md) | 原后台的文件结构、接口和行为记录，供取得源码后核对 |
| [`config/discovery-sources.json`](config/discovery-sources.json) | 公告来源与访问方式 |
| [`config/search-presets.json`](config/search-presets.json) | 软件、音视频、RTC 等查询词与查询模板 |

## 如何执行

1. 阅读[执行流程](docs/workflows.md)，以本次执行的北京时间确定检索范围。
2. 使用 `config/` 中的来源和关键词发现候选项目，到官方公告核对项目编号、采购范围、报名／领件及响应截止时间。
3. 核对更正、延期、终止公告；将证据、核验时间和未知项一并记录。下载公开采购文件并分析；需要登录、付款或现场领取时记录明确的办理步骤。
4. 按项目与标包去重，合并已跟进项目，保留既有参与决策、领件状态、历史截止时间及附件。
5. 按统一北京时间和项目生命周期规则统计，输出新增、更新、临近截止、待核验、已过期及已弃标清单。

这些文件是供人或具备联网能力的执行代理使用的操作说明和配置，尚未提供定时采集程序或 GitHub Actions 自动采集任务。来源网站需要实际访问验证，部分平台需要登录或人工办理。

## 来源与验证范围

内容依据用户提供的“查找招标网音视频与RTC项目”对话整理，详见[来源与验证范围](docs/workflow-provenance.md)。对话中列出的历史项目、时间、数量和测试结果不代表当前线上状态。本仓库未导入历史项目台账，也未将旧项目列表作为“最新项目”发布。

原始对话只记录了后台文件读写摘要，未包含完整源码。取得源码后按 [`backend/README.md`](backend/README.md) 导入并重新验证；目前不宣称与既有线上系统兼容或可部署。

## 数据与凭据

版本库仅收录代码、脱敏配置及流程说明。运行数据、数据库、真实附件、账户凭据、采购注册材料和原始对话应保存在版本库之外。`.gitignore` 可减少误提交，但导入前仍需逐项检查文件；它不会移除已经提交的内容。
